# AM4 Route Calculator

Unofficial fan tool for **Airline Manager 4**: finds the optimal aircraft type and seat configuration for a route and calculates its profitability (single aircraft or a whole fleet).

Live: <https://globalairall.net/tools/am4calc.html> · Description: <https://globalairall.net/tools/am4calc_description.html>

## Structure

| Part | Where | Repository |
| --- | --- | --- |
| Logic and tool styles | `site/tools/route_calculator/am4calc.js`, `am4calc.css` → `www/tools/route_calculator/` | this one |
| Pages (`am4calc.html`, `am4calc_description.html`) | `www/tools/` | [website](https://github.com/Global-Air-Alliance/website) (Bootstrap Studio) |
| Aircraft list, game data, shared styles | `www/tools/shared_resources/` | [AM4-Tools_Shared_Resources](https://github.com/Global-Air-Alliance/AM4-Tools_Shared_Resources) |

The page loads `shared_resources/am4.js` first, then `route_calculator/am4calc.js`.

## Language

The tool is written in English only and translated on the website by Linguise.
Texts generated by the script are read from the hidden block `<div id="am4-strings">` of the page (`AM4.strings()`), so Linguise translates them together with the page. Containers filled by the script and the country/airport selects carry the class `no-translate`. Numbers are formatted in the visitor's browser locale.

## Deployment

Every push to `main` that changes `site/` runs the workflow **Deploy Route Calculator** (`.github/workflows/deploy.yml`): rsync over SSH to `www/tools/route_calculator/`, then a message per commit in the Discord forum post of the tool; on failure an e-mail. Variables and secrets are listed at the top of the workflow file.
